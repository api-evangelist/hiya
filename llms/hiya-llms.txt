# Hiya

> Hiya is an AI-native voice security company that blocks spam, fraud, and deepfake calls at network scale for mobile operators, enterprises, and consumers. Its developer platform (developer.hiya.com) exposes REST APIs served over HTTPS from api.hiya.com using HTTP Basic authentication (App ID + App Secret), with bearer tokens for Audio Intelligence, plus iOS and Android mobile SDKs.

This llms.txt was generated by the API Evangelist enrichment pipeline from the Hiya developer portal and the repo's captured artifacts. Method: generated (no provider-published /llms.txt was found).

## APIs

- [Hiya Connect API](https://developer.hiya.com/docs/connect/branding/endpoints/v-1-register-outbound-call): Branded outbound calling — register originating numbers, manage Connect phone numbers and managed brands, upload/manage logos, read branded-phones cache and billing analytics.
- [Hiya Protect API](https://developer.hiya.com/docs/protect/cache/endpoints/v-1-get-profile-phones-cache): Spam/scam protection — business partner reputation, spammer and profile-phone caches (gzipped TSV), voice scam protection session reporting.
- [Hiya Audio Intelligence API](https://developer.hiya.com/docs/audio-intel/introduction): Audio authenticity, identity, and voiceprint verification for deepfake / synthetic-voice detection. Base URL https://api.hiya.com/audiointel/{region}/v1.
- [Hiya AI Voice Platform API](https://developer.hiya.com/docs/ai-voice-platform/introduction): Call logs, contacts, relations, user preferences, notification tokens, call feedback, assistant voices, and a live-calls websocket.
